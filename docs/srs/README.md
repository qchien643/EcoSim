# SRS — Đặc tả yêu cầu hệ thống

Thư mục này mô tả **sản phẩm phải cung cấp những gì**. Nội dung không phụ
thuộc vào JEV, vector search, công nghệ cơ sở dữ liệu hay lựa chọn triển khai
cụ thể nào.

## Tài liệu

- [01 — Yêu cầu hệ thống](01-system-requirements.md)

## Trạng thái yêu cầu

- **Đã xác nhận:** đã được thống nhất trong quá trình trao đổi.
- **Bản nháp:** cách diễn giải đề xuất, cần tiếp tục review.
- **Còn mở:** chưa đủ rõ để trở thành yêu cầu chính thức.

Các hành vi chức năng nằm trong thư mục [`../frd/`](../frd/). Chi tiết model,
thuật toán, schema và tích hợp nằm trong các tài liệu kỹ thuật riêng.
